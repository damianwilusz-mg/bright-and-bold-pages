# Dual Theme Landing Pages

Chciałbym abyś przygotował dla mnie landing-page w języku angielskim (oraz polskim) wraz z dwoma wersjami: light i dark mode.

Wzoruj się na: https://www.bstefanski.com/

Dane do Landing Page na screenie, ale możesz też napisać o tym, że siedzę w TypeScript, Node.js oraz PHP (Laravel).
